

# Pull Request (PR) 가이드

## 📌 PR 생성 전 체크리스트
- [ ] 기능 개발 완료
- [ ] 로컬 테스트 및 정상 동작 확인
- [ ] 불필요한 코드 제거 (console.log, 주석 등)
- [ ] 코드 컨벤션 준수
- [ ] 관련 이슈 연결 (ex. #1)

---

## ✨ PR 작성 규칙

### 1. 제목
- `[Feature] 기능명`
- `[Fix] 버그 내용`
- `[Refactor] 리팩토링 내용`

예시:
- [Feature] 회원가입 기능 추가
- [Fix] 로그인 시 토큰 오류 수정

---

### 2. 내용
다음 내용을 포함해주세요:

- **변경 사항**
  - 어떤 기능을 추가/수정했는지

- **변경 이유**
  - 왜 이 작업이 필요한지

- **테스트 방법**
  - 어떻게 테스트하면 되는지

---

## ⚠️ 주의사항
- 하나의 PR에는 하나의 목적만 담기
- 너무 큰 PR은 지양 (리뷰 어려움)
- 리뷰어가 이해하기 쉽게 작성
- 동작 화면 또는 API 결과 첨부 권장

---

## 🔄 PR 이후
- 리뷰 피드백 반영
- 필요 시 추가 커밋
- 승인 후 Merge 진행

---

## 🚫 금지 사항
- 동작 확인 안 된 코드 PR 금지
- 불필요한 파일 포함 금지
- 큰 변경을 설명 없이 올리는 것 금지
